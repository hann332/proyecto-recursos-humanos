# Datos del Proyecto de Recursos Humanos

## Descripción

Esta carpeta contiene los archivos de datos utilizados en el análisis de Recursos Humanos de una empresa ficticia

## Archivos

- **departamentos.csv:** catálogo de departamentos de la empresa
- **empleados.csv:** información de los empleados, incluyendo departamento, puesto, ciudad, fechas de ingreso y baja, y estatus laboral
- **salarios.csv:** registros salariales de los empleados, con fechas de inicio y fin de vigencia

Los archivos limpios se utilizaron para realizar las consultas SQL y preparar los datos del dashboard en Looker Studio

## Preparación de los datos

Los datos se revisaron y limpiaron en Excel para mejorar su consistencia y facilitar el análisis. El proceso incluyó la eliminación de registros duplicados, la normalización de textos, la revisión de valores faltantes y la estandarización de fechas

## Consideraciones

- Los datos son ficticios y se utilizan exclusivamente con fines de aprendizaje y demostración
- Se conservaron los registros salariales con valores faltantes para documentar las limitaciones de los datos
- Los resultados del análisis dependen de la calidad y consistencia de los archivos utilizados
