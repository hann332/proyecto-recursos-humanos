# Dashboard de Recursos Humanos

Dashboard interactivo desarrollado en Looker Studio para analizar indicadores de personal de una empresa ficticia

## Indicadores principales
- Empleados activos y bajas
- Tasa de rotación
- Salario promedio de empleados activos
- Antigüedad promedio
- Distribución de empleados por departamento, género y ciudad
- Contrataciones por año

## Herramientas
- Looker Studio
- Google Sheets
- SQL (SQLite)

## Datos
Se utilizan datos ficticios con fines de práctica y aprendizaje

## Visualización
El dashboard se desarrolló en Looker Studio
