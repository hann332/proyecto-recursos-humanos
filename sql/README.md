# Análisis de Recursos Humanos con SQL

## Descripción

Esta carpeta contiene las consultas SQL desarrolladas en SQLite para analizar la información de empleados, departamentos y salarios de una empresa ficticia

## Consultas realizadas

1. **Empleados activos y bajas:** contabiliza los empleados según su estatus laboral
2. **Salario promedio por departamento:** calcula el salario mensual promedio de los empleados activos
3. **Rotación por departamento:** identifica la proporción de bajas en cada departamento
4. **Antigüedad promedio:** calcula los años de permanencia promedio de los empleados activos
5. **Ingresos por año:** analiza la cantidad de empleados contratados en cada año
6. **Distribución por género y ciudad:** muestra la composición del personal según estas variables
7. **Tabla para el dashboard:** combina información de empleados, departamentos y salarios para preparar los datos de visualización

## Herramientas

- SQLite
- DB Browser for SQLite
- Consultas SQL con `SELECT`, `JOIN`, `GROUP BY`, `CASE`, funciones de agregación y subconsultas

## Objetivo
Utilizar SQL para transformar los datos de Recursos Humanos en indicadores que permitan analizar la distribución del personal, los salarios, la rotación y las contrataciones

## Consideraciones

Los datos utilizados son ficticios y se emplean exclusivamente con fines de aprendizaje y demostración
